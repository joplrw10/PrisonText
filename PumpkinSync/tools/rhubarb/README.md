# Optional Rhubarb Lip Sync executable

PumpkinSync works without Rhubarb. To enable Rhubarb's phoneme-oriented A-H/X cue generation, place the executable here using one of these names:

- Windows: `rhubarb.exe`
- Linux: `rhubarb`

Alternatively, put Rhubarb on `PATH` or set `PUMPKINSYNC_RHUBARB` to the executable's full path. Rhubarb itself is not redistributed with PumpkinSync.
