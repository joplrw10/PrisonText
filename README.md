# PumpkinSync

This repository hosts **[PumpkinSync](PumpkinSync/README.md)**, a local browser editor that turns a song or spoken skit into a lip-synced, projector-ready pumpkin performance video.

- Quick start: [`PumpkinSync/START_HERE.txt`](PumpkinSync/START_HERE.txt)
- Full guide: [`PumpkinSync/README.md`](PumpkinSync/README.md)
- Design notes: [`PumpkinSync/docs/design.md`](PumpkinSync/docs/design.md)

Private, user-specific face templates are intentionally not stored in this repository; see [`PumpkinSync/USER_MEDIA_NOTICE.md`](PumpkinSync/USER_MEDIA_NOTICE.md).
